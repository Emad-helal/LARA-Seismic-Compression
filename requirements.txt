# ---------------------------------------------------------------------------
# Notes
# ---------------------------------------------------------------------------
# 1. The notebooks are Python 3.11 and 3.12; either works. The bit-rate script
#    overrides the notebook data paths and forces device="cpu", so it can be run
#    on a machine with no GPU.
# 2. `constriction` is not optional. The entropy coder in arithcoder.py is built on
#    it, and a hand-written coder was discarded earlier in this work because it
#    desynchronised. Every reported rate is verified by decoding the trace back.
# 3. Determinism: the training notebooks set torch/numpy/random seeds to 42 and
#    call set_seed(42) before every (CR, arm) pair, so all ablation arms at a
#    given ratio start from identical weights. The cost benchmark runs each thread
#    count in a separate process, because switching the OpenMP pool inside one
#    process inflates single-thread latency by an order of magnitude.
# 4. Expected runtimes on an RTX 4080 SUPER:
#       Final_LARA_27092026.ipynb              the main 60-configuration study
#       Final_Ablation_27092026.ipynb          50 configurations, ~18 h
#       build_loss_ablation_LARA_27092026.py   70 configurations, ~8-9 h
#    Run every script with --smoke first to verify the pipeline in ~2 minutes.
